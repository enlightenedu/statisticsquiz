# 课程作业答题系统 · 使用说明

一个**单文件网页程序**，学生点击作答、系统自动判分并汇总成绩；老师可管理题库、班级和成绩。

---

## 一、文件说明

| 文件                       | 作用                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `index.html`             | **主程序（联网版）**。填了 Supabase 密钥就联网共享数据；不填密钥就是纯本地版。部署到 GitHub Pages 用这个。 |
| `quiz-system-local.html` | **纯本地版备份**（数据存在浏览器里，单人单机用）。                                                         |
| `supabase-schema.sql`    | 云数据库（Supabase）建表脚本，联网部署时用一次。                                                                 |
| `storage-setup.sql`      | 文件上传存储桶初始化脚本，**用「上传题」功能前**执行一次。                                                 |
| `README.md`              | 本说明文档。                                                                                                     |

> 联网版（index.html）和本地版功能完全一致，只是数据存的地方不同。

---

## 二、功能清单

1. **六种题型**：单选题、多选题、简答题、计算题、分析题、**上传题**（学生提交作业文件，老师下载批改）。
2. **自动判分**：
   - 单选：选项精确匹配；
   - 多选：逐选项判断（漏选、多选按比例扣分）；
   - 简答 / 分析：按关键词分组、命中比例给分；
   - 计算：数值答案（可设误差范围）+ 计算过程关键词（要写过程才有步骤分）。
3. **分套（章节）管理**：每套题单独设计、单独汇总，可增删改；每套可指定**由哪个班级作答**。
4. **套内自动排序**：每套题按「一、单选 二、多选 三、简答 四、计算 五、分析」自动排列。
5. **统一入口 + 密码，角色区分**：
   - 学生：只能进入「答题」模块；
   - 老师：可进入「答题 / 成绩汇总 / 题库管理」三个模块。
6. **学生管理**：按班级添加/导入学生信息（专业、学号、姓名、性别）；学生登录必须**姓名 + 学号同时匹配**；删除某学生或某班级后，该生即无法登录。
7. **成绩汇总**：参加人数、平均分、最高分、最低分、满分 + 每题得分明细；可**导出 CSV**（Excel 可直接打开）。
8. **修改密码**：老师登录后右上角「🔑 修改密码」。
9. **数据导入导出**：学生名单 CSV 导入/导出、套题 JSON 导入/导出、成绩 CSV 导出。

## 四、本地使用（不联网、不用数据库）

直接**双击打开 `index.html` 或 `quiz-system-local.html`** 即可，用浏览器（Chrome / Edge）打开。数据保存在这台电脑的浏览器里。

## 五、联网使用（让学生通过链接作答）

### 第 1 步：注册 Supabase 并建表

1. 打开 https://supabase.com ，用 GitHub 账号登录（免费）。
2. 新建一个 Project（地区选 Singapore 或 Tokyo 离国内较近）。
3. 左侧 **SQL Editor → New query**，把 `supabase-schema.sql` 的**全部内容粘贴进去 → Run**。

### 第 2 步：把密钥填进 index.html

1. Supabase 左侧 **Project Settings → API**（或点项目右上角绿色 **Connect** 按钮）里找到：
   - **Project URL**（形如 `https://xxxx.supabase.co`）
   - **anon public key**（以 `eyJ...` 开头的一长串）
2. 打开 `index.html`，找到文件开头附近的两行：
   ```js
   var SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
   var SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
   ```

   把 `YOUR-PROJECT.supabase.co` 和 `YOUR-ANON-KEY` 换成上面拿到的值，保存。

### 第 3 步：发布到 GitHub Pages

1. 登录 https://github.com ，右上角 **+ → New repository**，名字填 `quiz`，选 **Public**，不勾 README，**Create repository**。
2. 点 **uploading an existing file**（或 **Add file ▾ → Upload files**），把 `index.html` 拖进去，**Commit changes**。
3. 仓库 **Settings → Pages → Source 选 main 分支、/ (root) → Save**。
4. 等 1~2 分钟，得到链接：`https://你的用户名.github.io/quiz/`。

学生打开这个链接 → 姓名+学号作答；你在同一链接用密码 123456 登录即可进入全部三个模块。

### 第 4 步：启用「上传题」（文件作业）—— 只需一次

1. 回到 Supabase 控制台 **SQL Editor → New query**，把 `storage-setup.sql` 的**全部内容粘贴进去 → Run**。
2. 完成后，老师即可在「题库管理」里把题型选为「上传题」，学生作答时上传图片 / Word / PDF，老师到「成绩汇总」点「📎下载」批改。

## 六、注意事项

- **防作弊边界**：自动判分在浏览器前端完成，题目答案会随网页下发给学生（这与本地版一致），且 Supabase 用的是公开的 anon key。适合**课程作业 / 随堂练习**，不适合严格监考的正式考试。如需更严格，可接入 Supabase Auth 做真正登录鉴权。
- **国内网络**：GitHub Pages + Supabase + jsdelivr 在国内可能偏慢或偶尔打不开；若学生都在国内，可改 **Gitee Pages + LeanCloud** 方案。
- **数据备份**：建议老师定期在「成绩汇总」页**导出 CSV**，以及在题库管理里导出套题 JSON，作为备份。

---

## 七、常见问题

- **打不开链接 / 空白**：确认 index.html 里的两个密钥已填对；确认仓库已开启 Pages 且选的是 main 分支根目录。
- **学生登录提示「姓名或学号不对」**：去「学生管理」确认该生的姓名、学号与名单一致，且该套题已勾选其所在班级。
- **看不到成绩**：确认学生提交时用的是联网版链接（不是自己电脑上的本地文件）。
